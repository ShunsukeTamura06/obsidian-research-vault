# 業務コンテキスト

このドキュメントは、この vault を利用する会社業務の前提を記録する。
マスク済みの値はプレースホルダとして扱い、実値を推測しない。

## ワークスペース

| 区分 | 内容 |
|---|---|
| ローカルワークスペース | 社内で別途共有されるローカル作業領域 |
| クラウドワークスペース | 社内で別途共有されるクラウド検証環境 |
| リモートリポジトリ | 社内リモートリポジトリ |

## 調査・コミュニケーション

| 区分 | 利用ツール |
|---|---|
| 調査や調べ物 | 社内外の調査ツール |
| チャット | 社内チャット |
| オンライン会議 | オンライン会議ツール |
| 会議トランスクリプト | 文字起こしツール |

## 運用ルール

- 社内サービスの未マスク URL、認証情報、内部識別子、個人 ID は vault に保存しない。
- 社内チャットや会議ツールの内容は、業務上の決定事項・依頼事項・事実確認に絞って取り込む。
- 調査ツールの回答は一次情報として扱わず、可能な限り公開情報や社内資料で裏取りする。
- 会議トランスクリプトは `raw/meetings/` に保存し、`wiki/` には合意事項・論点・未決事項だけを合成する。
- 社内リモートリポジトリへ push する前に、`raw/`、`daily/`、`inbox/` に実データが含まれていないことを確認する。

## 理想運用

日中は通常どおり業務し、チャットコピー、会議 transcript、LLM 会話ログ、差分要約などを
`inbox/drop/` に投げ込む。

素材は手動コピー、ファイル移動、または社内スクリプトで自動配置してよい。
Claude は `daily-sync` skill でその素材を読み、継続利用すべき知見だけを `wiki/` に合成し、
作業履歴を `daily/` に残し、処理済みファイルを `inbox/processed/YYYY-MM-DD/` に移動する。
