# lint-wiki

## トリガー
- 「wiki を lint して」
- 「wiki チェックして」
- 「wiki の健全性確認」

## 手順

### 1. 構造的問題の検出

- **リンク切れ**: `[[X]]` で参照されているが存在しないページ
- **孤立ページ**: どこからもリンクされていないページ（inbox 経由のみは可）
- **frontmatter 不備**: title/date/tags のいずれかが欠落
- **タグ規約違反**: 銘柄ページに `#銘柄` が無い、概念ページに `#concept` が無い等

### 2. 内容的問題の検出（best-effort）

- **矛盾の可能性**: 同じ事実について異なる記述があるページペア
- **古い情報**: 1 ヶ月以上前の日付で「最新」「今後」等の表現
- **出典欠如**: 数値・固有名詞があるのに sources frontmatter も本文出典も無い

### 3. レポート出力

`outbox/lint-report_YYYY-MM-DD.md` に出力:

```markdown
# wiki lint レポート 2026-05-18

## 構造的問題

### リンク切れ (3件)
- [[銘柄/トヨタ自動車]] が [[wiki/マクロ/円安動向]] から参照されているが存在しない
- ...

### 孤立ページ (2件)
- [[wiki/ai-trends/旧モデル比較]] — どこからもリンクされていない
- ...

### frontmatter 不備 (5件)
- [[wiki/銘柄/X社]] — tags が空
- ...

## 内容的問題（要確認）

### 矛盾の可能性 (1件)
- [[A]] では「2026 Q1 に発表」、[[B]] では「2026 Q2 に発表」と記述

### 出典欠如 (4件)
- [[wiki/マクロ/インフレ動向]] L23: 「3.2%」という数値に出典なし
- ...

## 推奨アクション
- 上位 3 件のリンク切れを優先修正
- ...
```

### 4. 自動修正は**しない**
lint は検出のみ。修正は人間または別セッションで判断。

## 完了条件
- レポートが outbox/ に出力されている
- 検出件数を 1 行で報告
