# capture

## トリガー
- 「これ capture して」+ URL/パス/テキスト
- 「これ取り込んで」
- 「raw に入れて」
- 「整理して」（コンテキストに資料がある場合）

## 手順

### 1. ソース取得
- URL: web fetch して本文抽出
- パス: ファイル読み込み
- テキスト: そのまま使用
- 調査ツールの結果: 出典 URL、検索日、引用元が分かる範囲を本文に残す
- 社内チャット: 業務上の決定事項・依頼事項・事実確認だけを抽出し、機密情報はマスクする
- 会議・文字起こしツールのトランスクリプト: 会議名、日時、参加者、取得元を記録する

### 2. 種別判定 → 保存先決定

| 内容 | 保存先 |
|---|---|
| 一般ニュース・記事 | `raw/news/` |
| 適時開示・決算短信・有報 | `raw/disclosures/` |
| 議事録・面談メモ | `raw/meetings/` |
| 社内チャットの重要な業務メモ | `raw/meetings/` |
| 会議・文字起こしツールのトランスクリプト | `raw/meetings/` |
| 上記いずれでもない | `inbox/` |

ファイル名: `YYYY-MM-DD_短いスラグ.md`（slug は内容から決定、英数 + ハイフン）

### 3. 内容読解・抽出
- 主題（1行サマリ）
- 登場する固有名詞・概念（人名、企業名、技術名、概念名）
- 数値・日付
- 主張と根拠

### 4. wiki 影響範囲特定
- 抽出した固有名詞・概念を `wiki/` 全体で grep
- 最低 5 ページ、最大 15 ページの影響候補を特定
- 候補が 5 未満なら、関連分野のページを追加で探す

### 5. wiki 更新
影響ページごとに:
- 該当セクションに **追記**（全面書き換え禁止）
- 新しい関連がある場合は Wikilink を追加
- 出典として `sources:` frontmatter に raw ファイルへのリンクを追加

新規概念は `wiki/<カテゴリ>/<名前>.md` で作成。CLAUDE.md の frontmatter ルールに従う。

### 6. daily ログ
`daily/YYYY-MM-DD.md` に追記（無ければ作成）:

```markdown
- HH:MM /capture: <ソース1行サマリ>
  - source: [[raw/news/2026-05-18_xxx]]
  - 更新: [[A]], [[B]], [[C]]
  - 新規: [[D]]
```

## 完了条件
- raw に原文が保存されている
- wiki が最低 1 ページ更新されている
- daily にログが残っている
- ユーザーに 1 行で結果報告（「○件のwikiを更新、○件新規作成」）

## やらないこと
- raw/ の既存ファイルの編集・上書き
- 出典不明な情報の追加
- 1 ソースで 10 ページ以上の wiki 新規作成
- 未マスクの社内 URL、クラウド検証環境、社内リポジトリ、認証情報の保存
