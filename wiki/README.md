# wiki/

このフォルダは **Claude が維持する合成知識ベース** です。
人間が直接編集することもできますが、原則として:

- **新規追加**: `/capture` 経由で Claude に依頼
- **修正**: 直接編集してから、Claude に「直したから内容を踏まえて」と伝える
- **削除**: ユーザーが手動で実行

## グラフビュー方針

Obsidian のグラフビューで意味のあるネットワークになるよう、wiki ページは単独メモではなく相互リンクされたノードとして管理します。

- Wikilink は必ずフルパスで書く: `[[systems/顧客管理API]]`
- 新規ページは最低 3 件の関連 Wikilink を本文に含める
- 既存ページ更新時は、新しく関係が生まれたページへリンクを追加する
- 重要な関係は、可能な範囲で相手ページ側にも戻りリンクを追加する
- `aliases` に略称、別名、英語名、日本語名を入れ、検索とリンク候補を増やす
- 単なる作業ログは wiki 化せず、再利用できる概念・要件・設計判断・運用知見だけをノード化する

## サブフォルダ

| フォルダ | 用途 |
|---|---|
| `research/` | 技術調査、比較検討、検証メモから昇格した知見 |
| `requirements/` | 要件定義、業務要件、非機能要件、制約条件 |
| `systems/` | システム、API、DB、バッチ、連携、アーキテクチャ |
| `operations/` | 保守運用、障害対応、手順、監視、問い合わせ対応 |
| `decisions/` | 設計判断、会議での決定事項、未決論点の整理 |

実運用では自分の領域に合わせて改名・追加してください。
